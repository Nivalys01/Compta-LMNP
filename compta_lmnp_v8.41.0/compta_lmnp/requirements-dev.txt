# Un linter non épinglé transforme une release de l'outil en CI rouge : le
# jeu de règles par défaut de ruff s'est élargi entre deux versions et le
# projet est passé de « propre » à 234 erreurs sans qu'une ligne de code
# ait changé. Le jeu de règles est par ailleurs déclaré dans pyproject.toml.
pytest==8.3.4
ruff==0.16.0

# reportlab n'est pas de l'outillage : c'est une dépendance RUNTIME de
# liasse_pdf.py, que les lanceurs installent chez l'utilisateur (sans
# l'épingler, et sans bloquer si elle échoue — tout marche sauf l'export
# PDF). Elle figure ici parce que sans elle cinq tests de la suite
# échouent sur un ModuleNotFoundError : un environnement de développement
# incomplet donnait cinq échecs permanents qu'on finissait par ignorer,
# c'est-à-dire le pire état pour une suite de tests.
reportlab==5.0.1
